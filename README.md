# AI-slop-not-the-smartest-student 🎓

Графическое приложение на **PySide6 (Qt6)** для решения 18 практических задач по программированию и математике.

Интерфейс приложения разделен на тематические категории. Для каждой задачи предоставляется интерактивная форма ввода данных, автоматический расчет с валидацией и **просмотр исходного кода алгоритма** с подсветкой синтаксиса Python.

---

## 📁 Структура проекта

* `logic/` — изолированные математические алгоритмы и исходный код для каждой из 18 задач.
* `ui/` — графический интерфейс на PySide6:
  * `styles/` — тёмная QSS-тема и кастомный синтаксический подсветчик (`QSyntaxHighlighter`).
  * `tabs/` — тематические группы вкладок (*Измерения*, *Алгебра*, *Геометрия*, *Экономика*).
* `utils/` — валидаторы пользовательского ввода и форматирование вывода.
* `shell.nix` — декларативная конфигурация окружения для NixOS.
* `main.py` — точка входа в приложение.

---

## 🛠 Реализованные задачи (1–18)

1. **Конвертер ГМС ➔ Радианы** (поддержка углов > 180° и отрицательных значений).
2. **Конвертер Радианы ➔ ГМС**.
3. **Перевод длины из дюймов** в метры, сантиметры и миллиметры.
4. **Расчет интервала времени** в пределах суток (чч:мм:сс).
5. **Моделирование накоплений коммерсанта** (сложный процент по месяцам).
6. **Расчет воспроизводства семян селекционера** (экспоненциальный рост).
7. **Восстановление коэффициентов кубического уравнения** по корням $a, b, c$.
8. **Тригонометрическая форма комплексного числа** $z = r(\cos\varphi + i\sin\varphi)$.
9. **Угол между пересекающимися прямыми** $y = k_1 x + b_1$ и $y = k_2 x + b_2$.
10. **Русские неметрические единицы длины** (версты, сажени, аршины, вершки).
11. **Расчет сторон равнобедренного прямоугольного треугольника** по высоте $h$.
12. **Вершина параболы** $y = ax^2 + bx + c$.
13. **Аппроксимация $\sin(x)$** рядом Тейлора и сравнение с точным значением.
14. **Внутренние углы треугольника** по 2D-координатам вершин $A, B, C$.
15. **Угол между 3D-векторами** $\vec{A}$ и $\vec{B}$.
16. **Сезонная динамика цен на молоко** за $n$ лет (+p% зимой, -p% летом).
17. **Координаты вершин квадрата** $B$ и $D$ по противоположным точкам $A$ и $C$.
18. **Корни квадратного уравнения** ($D > 0$) с подстановкой для оценки погрешности.

---
